
# NAINA AI

## 🚀 Overview

NAINA AI is an open-source AI desktop assistant for Windows. It is designed to automate desktop tasks, control applications, execute voice commands, and improve productivity using modern AI technologies.

---

## ✨ Features

- 🎤 Voice Command Support
- 🖥️ Desktop Automation
- 📂 File & Folder Management
- 🚀 Application Launcher
- 🤖 AI Chat Assistant
- ⚡ Command Execution
- 🌐 Browser Automation
- 🔍 Smart Search
- 📝 Task Automation
- 🧠 Modular AI Architecture

---

## 🛠️ Tech Stack

- Electron
- React
- Node.js
- Python
- JavaScript
- HTML
- CSS

---

## 📦 Installation

```bash
git clone https://github.com/anuj2664/naina-ai.git
cd naina-ai
npm install
```
