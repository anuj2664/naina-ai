# 🤖 NAINA AI – Your Personal AI Desktop Assistant

> **NAINA AI** is an open-source, next-generation AI desktop assistant for Windows, built to automate everyday computer tasks, control applications, execute voice commands, and boost productivity with the power of artificial intelligence.

---

# 🚀 Overview

NAINA AI transforms your computer into an intelligent personal assistant. Inspired by futuristic AI systems, it can understand commands, automate workflows, manage files, launch applications, browse the web, and assist you through natural conversations.

Whether you're a developer, student, content creator, or power user, NAINA AI helps you save time by automating repetitive desktop tasks.

# 📦 Installation

```bash
# Clone the repository
git clone https://github.com/anuj2664/naina-ai.git

# Navigate to the project folder
cd naina-ai
#pip install -r requirements.txt
# Install dependencies
npm install

# Start the development server
npm start
```
